# Billing (Оплата / Платёжная логика)

##  Задача

Ценообразование, создание платежей, интеграция с платёжными шлюзами.

## Назначение

Billing отвечает за **платёжную логику**:
- вычисление стоимости бронирования
- интеграция с платёжными шлюзами (Stripe, PayPal)
- захват средств и возвраты

Это не просто CRUD для платежей — Billing реализует **доменные правила ценообразования и биллинга**.

## Функционал

- правила ценообразования
- сопоставление прайсов по времени
- создание и подтверждение платежей
- возвраты / отмены
- интеграция с Stripe / PayPal
- события биллинга (PaymentCaptured, RefundIssued)

## Основные элементы

- Pricing rules
- Payment, PaymentIntent
- Events: `PaymentCaptured`, `RefundIssued`

## Взаимодействие

- Слушает события `BookingCreated` для инициации платежей
- Публикует Billing события, используемые Notification

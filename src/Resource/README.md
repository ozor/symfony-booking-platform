# Resource (Ресурсы)

##  Задача

Описывает, что именно можно бронировать.

## Назначение

**Resource** описывает объекты, доступные для бронирования:
- ресурсы (комнаты, оборудование, сотрудники и т.д.)
- рабочие часы, расписания
- исключения (праздники, блокировки)

Цель — аккуратно описать, **что можно бронировать и когда**.

## Функционал

- сущности ресурсов (залы, оборудование, мастера)
- рабочие графики / расписания
- буферы между брони
- вместимость / виды слотов
- исключения (праздники / недоступные дни)

## Основные элементы

- Сущности: `Resource`, `WorkingHours`, `Exception`
- VO: `Capacity`, `BufferTime`
- Events: `ResourceUpdated`

## Взаимодействие

- Отправляет события ResourceUpdated, чтобы Availability мог пересчитать слоты
- Используется Booking для ссылок на конкретные ресурсы

## Примечание

Resource содержит только предметную логику, без связей с API Platform или маппингом на инфраструктуру.

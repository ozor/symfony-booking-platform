# Shared (Общие компоненты)

##  Задача

Общие абстракции и инструменты, не относящиеся к конкретному бизнес-контексту.

## Назначение

Shared содержит **общие компоненты**, используемые всеми доменами:
- Value Objects (`Uuid`, `Money`, `Email`)
- Абстракции (CommandBus, EventBus)
- Общие Domain Events
- Утилиты и вспомогательные классы

## Функционал

- Value Objects (Email, Money, Uuid, DateRange)
- Abstractions (CommandBusInterface, EventBusInterface)
- базовые события (DomainEvent)
- инфраструктурные адаптеры (общие)

## Особенности

Shared — не предметная доменная логика, а **повторно используемые артефакты**.

## Примечание

Следует избегать слишком широких зависимостей Shared → Domain, чтобы не размывать границы контекстов.

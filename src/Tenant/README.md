#  Tenant (Арендаторы / Организации)

##  Задача

Управление организациями, которые используют платформу (их настройки, тарифы, ограничения).

## Назначение

Контекст **Tenant** управляет организациями (арендаторами), использующими платформу:
- регистрация арендатора
- настройки арендатора (таймзона, правила, лимиты)
- привязка пользователей к арендаторам

Tenant обеспечивает **границы ответственности для разных клиентов системы**.

## Функционал

- регистрация и конфигурация арендатора 
- тарифные планы и лимиты
- часовой пояс арендатора (для расчёта времени)
- привязка пользователей к арендаторам

## Основные элементы

- Сущность: `Tenant`
- VO: `TenantId`
- Policies: правила доступа, конфигурации

## Взаимодействие

Tenant используется в Booking, Resource и User для определения прав и контекста выполнения.

# Availability (Доступность)

##  Задача

Расчёт доступных временных слотов для каждого ресурса.

## Назначение

Availability отвечает за расчёт **доступных временных слотов** для ресурсов с учётом:
- расписания ресурса
- исключений (нерабочие дни, праздники)
- уже существующих бронирований

Этот контекст служит интерфейсом для проверки доступности перед созданием брони.

## Функционал

- генерация доступных интервалов
- учёт расписания, исключений и буферов
- учёт существующих бронирований
- выдача доступности для фронта / API
- Обычно этот модуль получает события от Booking и Resource и обновляет кэш доступности.

## Основные элементы

- `AvailabilitySlot`, `TimeSlot`
- Алгоритм AvailabilityCalculator
- Кэш (Redis) для быстрого ответа

## Взаимодействие с другими контекстами

- Слушает события `BookingCreated` и `BookingCancelled`
- Слушает события `ResourceUpdated` для сброса кэша

## Примечание

Availability не содержит HTTP/API-логику — он предоставляет сервисы для использования из Application слоя.

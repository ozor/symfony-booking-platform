# Notification (Уведомления)

##  Задача

Асинхронная система отправки уведомлений пользователям и администраторам.

## Назначение

Notification обеспечивает отправку уведомлений по событиям:
- email уведомления
- webhook уведомления на сторонние системы
- другие виды (смс, push — расширяется по необходимости)

Этот контекст реализует **асинхронную отправку сообщений**, отделяя уведомления от основной бизнес-логики.

## Функционал

- отправка email / webhooks / push
- шаблоны уведомлений
- очереди (через Messenger)
- реакция на события бронирования, платежей

## Основные элементы

- Notification templates
- Notification sender services
- Handlers для событий Booking/Billing

## Взаимодействие

Подписан на события из Booking и Billing, отправляет сообщения или webhooks.

# Booking (Бронирования) — Core Domain

##  Задача

Управление жизненным циклом бронирований.

## Назначение

Контекст **Booking** отвечает за весь жизненный цикл бронирования ресурсов в системе:
- создание бронирования
- отмена и подтверждение
- управление статусами и сроками
- валидация правил предметной области

Booking — это **сердце предметной логики**, которое соблюдает бизнес-правила и изолирует логику бронирования от инфраструктуры.

## Функционал

- создание брони
- отмена
- подтверждение
- обработка повторяющихся бронирований
- статусы (pending, confirmed, cancelled, etc.)
- лист ожидания
- генерация доменных событий (BookingCreated, BookingCancelled, …)

Это центральный домен, вокруг которого выстраиваются Billing, Availability, Notification.

## Основные элементы

- **Агрегат Booking** — корень, обеспечивающий согласованность
- **Value Objects** — `BookingId`, `DateRange`, и т.п.
- **Domain Events** — `BookingCreated`, `BookingCancelled`, …
- **Domain Services/Policies** — правила валидации

## Взаимодействие

- Отправляет доменные события в Availability, Billing и Notification
- Не зависит от инфраструктурных деталей (ORM, HTTP, API Platform)
